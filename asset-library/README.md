# 数字资产库

集中存放个人/课题组的全部科研成果，按类别分目录管理。

## 目录结构

| 目录 | 放什么 |
| --- | --- |
| `01-论文/` | 期刊论文、会议论文、学位论文 |
| `02-专利/` | 专利申请书、受理通知、授权证书 |
| `03-软件著作权/` | 软著证书与申请材料 |
| `04-获奖与荣誉/` | 奖励证书、竞赛获奖、荣誉称号 |
| `05-项目与课题/` | 申报书、任务书、合同、结题材料 |
| `06-报告与演示/` | 学术报告、海报、答辩 PPT |
| `07-数据集/` | 可复用的数据及说明 |
| `08-代码与软件/` | 代码、工具软件或仓库链接 |
| `09-图片与多媒体/` | 原图、照片、视频 |
| `10-其他/` | 暂不好归类的成果 |
| `_templates/` | 成果信息模板 |

完整清单见 [INDEX.md](INDEX.md)。

## 怎么上传一项成果

1. 在对应类别下新建文件夹，命名为 `年份-简短标题`，例如 `01-论文/期刊论文/2025-某材料催化性能研究/`。
2. 把原始文件放进去（PDF、证书扫描件、PPT 等）。文件名尽量用英文或拼音，避免空格。
3. 复制 `_templates/info.md` 到该文件夹，填好标题、日期、作者、编号等信息。
4. 运行 `python3 build_index.py` 更新总目录 `INDEX.md`。
5. 提交并推送到 `beta` 分支。

也可以直接在 GitHub 网页上进入对应目录，点 **Add file → Upload files** 拖入文件（网页上传完后在本地跑一次第 4 步即可）。

## 注意事项

- **单个文件上限**：GitHub 网页上传 25 MB，命令行推送 100 MB。更大的文件（视频、原始数据）建议放网盘，在 `info.md` 里写链接；或者启用 [Git LFS](https://git-lfs.com/)。
- **隐私**：如果仓库是公开的，任何人都能看到这里的文件。未公开的专利申请、合同、含身份证号/手机号的证书扫描件，请先打码，或把仓库设为私有。
- 同一成果的不同版本（投稿版、修改版、终稿）放在同一个文件夹里，用 `v1`、`v2`、`final` 区分。
